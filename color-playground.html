Semantic roles

Each role is a CSS custom property (--color-primary and so on). Light and Dark are two separate palettes, not one inverted. The toggle chooses which palette the inputs below edit and the contrast checker tests. Both sample interfaces are always shown.

Editing the light palette.

Contrast checker: Light mode

WCAG contrast ratio for every text pair used in the sample interface, for the mode selected above. Normal text needs 4.5:1 for AA and 7:1 for AAA. Large text (24px regular or 19px bold) needs 3:1 for AA and 4.5:1 for AAA. Ratios are rounded down, so a 4.49 never shows as 4.5. Updates live with the role colors.
