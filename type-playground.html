Line height and tracking

Set per step, not once for everything. Line height is a multiple of the font size; tracking is in em (a fraction of the font size). Guideline: body about 1.5; large headings 1.1 to 1.25 with slightly negative tracking; all-caps labels a little positive; buttons none, or a little if all caps; body about zero. A note turns amber when a value is outside that guideline. It is a nudge, not an error.

Weight roles

Each role maps to a weight number. Headings and subheadings use the heading font; body, labels and buttons use the body font. H1 and H2 above use the heading role, H3 uses the subheading role, and body uses the body role.
